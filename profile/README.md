# The KafClaw Ecosystem: Production-Grade Agentic Infrastructure

This ecosystem provides the full vertical stack required to move AI agents from "cool demos" to "enterprise production." We don't just build bots; we build the nervous system, the memory, and the governance layer that agents need to operate autonomously and safely.

## Core Pillars

1. **Coordination (KafClaw)**: The backbone. Moving away from fragile point-to-point APIs to a robust, Kafka-driven message bus.
2. **Infrastructure (GitClaw)**: Agentic version control. Infrastructure that treats machine identities as first-class citizens.
3. **Data & Scale (KafScale)**: Cloud-native streaming. Stateless Kafka backed by S3, providing the throughput agents need without the operational overhead.
4. **Governance (Scalytics Connect)**: The control plane. Private AI operations with role-based access and full auditability.

## The Projects

### [KafClaw](https://github.com/KafClaw/KafClaw) — The Nervous System
KafClaw is a Go-based framework that enables multi-agent collaboration over Apache Kafka.
* **Why it exists**: Agents need observability and durability. KafClaw uses typed JSON envelopes (announce, request, response, trace) to ensure every agent interaction is traceable and replayable.
* **Technical Highlight**: Species-independent coordination. Whether an agent is written in Go, Python, or Rust, it participates in the group by simply following the Kafka wire protocol.

### [GitClaw](https://github.com/KafClaw/GitClaw) — Agent-First Git
A hard fork of Gitea designed specifically for agentic workflows.
* **Why it exists**: Humans use emails and passwords; agents use machine identities and tokens. GitClaw introduces deterministic enrollment APIs that allow agents to join an instance and start collaborating via Git without manual human intervention.
* **Technical Highlight**: Automated agent enrollment policy and token lifecycle management built directly into the core.

### [KafScale](https://github.com/KafClaw/KafScale) — Stateless Streaming
The data layer for massive agent swarms.
* **Why it exists**: Traditional Kafka is disk-heavy and complex to scale. KafScale provides a stateless architecture that leverages S3 for storage, making it perfect for Kubernetes-native agent deployments that need to scale up and down instantly.
* **Technical Highlight**: Decouples compute from storage, allowing for infinite retention and sub-second scaling.

### [Scalytics Connect](https://github.com/KafClaw/Scalytics-Copilot) — Private AI Ops
The management layer for enterprise GenAI.
* **Why it exists**: Enterprises cannot run on "black-box" AI. This project provides the governance, role-based permissions, and data locality controls required to run agents in sensitive environments.
* **Technical Highlight**: A unified platform for both local and external models, ensuring that model access is a policy decision, not a coding one.

## Why We Built This

The world is going agentic, but production environments aren't ready.

Most agent frameworks assume a stable, low-latency environment with a single human controller. Real-world enterprise environments are distributed, messy, and require strict auditing.

We built this ecosystem to provide:
* **Interoperability**: Agents from different teams/languages working together.
* **Observability**: Knowing exactly why an agent took an action.
* **Security**: Machine-identity-based access control.
* **Scale**: Handling the "content explosion" generated by autonomous swarms.

**The KafClaw ecosystem is the foundation for the autonomous enterprise.**
